# Smart RPS Game 🎮

A Python-based Rock, Paper, Scissors game that supports custom option sets, persistent player ratings, and dynamic win–lose relationships.

## 🚀 Features
- 🪨 Supports custom sets beyond just rock–paper–scissors  
- 🧠 Automatically determines winning logic for any list of options  
- 💾 Saves and loads player ratings from `rating.txt`  
- 🏆 Earn points:  
  - +100 for a win  
  - +50 for a draw
